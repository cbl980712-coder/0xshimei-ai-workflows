# 国内网络下的环境搭建指南(没海外卡版)

## 先回答问题:国内到底能不能玩?
**能玩一半。** 教程里"拿行情 → 算信号 → 回测 → 提醒"这条链路完全可以在国内跑；"链上抢 Meme 币""海外券商下单""币安"这三件在大陆不可行，也不建议绕。

| 教程里的东西 | 国内能不能 | 平替 |
|---|---|---|
| GMGN / 链上 Meme 币 | ✗ 大陆不支持加密资产交易 | 保留"放量异动+风控"思路，盯 A 股高换手股 |
| Binance / OKX 行情 | ✗ | 沪深300ETF(510300)、黄金ETF(518880)、纳指ETF(513100) |
| Alpaca / IBKR / yfinance 行情 | 行情可替 | 腾讯财经日K、新浪实时报价(本脚本)；或 AkShare |
| 美股下单 | ✗(需海外账户) | 本地模拟盘；真要买美股敞口走境内合规 QDII/跨境 ETF |
| TradingView 回测 | 网页能开但要登录 | 本脚本内置回测(含佣金/印花税/整手) |
| OpenAI API | 直连不稳 | 盯盘不需要大模型；解读可贴给任意国产模型 |

## 环境(全程免费、免登录)
1. Python 3.8+，只用标准库，无需 pip。
2. 可选 AkShare：`python3 -m venv .venv && . .venv/bin/activate && pip install akshare`。国内 pip 慢可加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。
3. 数据接口(均为公开 HTTP，免 key):
   - 腾讯日K `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,250,qfq`
   - 新浪实时 `https://hq.sinajs.cn/list=sh600519`(必须带 `Referer: https://finance.sina.com.cn`，编码 GBK)

## A 股模拟盘规则(脚本已实现)
- T+1：信号当日收盘生成，次日开盘价成交。
- 整手：买入按 100 股取整。本金不够 1 手会跳过并在报告中提示。
- 涨停不买、跌停不卖(按 ±9.9% 近似；创业板/科创板 20%、ST 5% 未区分)。
- 费用：佣金万2.5(最低5元)，卖出印花税万5。

## 常见坑
- 新浪接口不带 Referer 会 403；返回是 GBK，要解码。
- 非交易时段实时价=收盘价，信号不会变，别误以为脚本坏了。
- 公开接口无 SLA，别高频轮询(默认 60 秒)；失败时脚本回退缓存并标注。
- 回测漂亮≠能赚钱：演示用的简单均线策略在例子里多数标的跑输或持平。
- 遇到"保赚""带单""荐股"收费服务，一律远离。
