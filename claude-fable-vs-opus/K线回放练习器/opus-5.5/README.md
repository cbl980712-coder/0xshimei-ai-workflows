# K 线回放练习器

双击 `index.html` 用浏览器打开即可，不需要联网、不需要服务器。

| 文件 | 作用 |
|---|---|
| `index.html` | 页面入口 |
| `app.js` | 回放、下单、止盈止损、统计、canvas 画图 |
| `style.css` | 样式（深色/浅色、手机适配） |
| `i18n.js` | 界面文字：简体中文、English、繁體中文、日本語、한국어 |
| `data.js` | 300 根模拟 BTC/USDT 1 小时 K 线（由 `gen_data.py` 生成） |
| `gen_data.py` | 数据生成脚本：`python3 gen_data.py [种子]`，换种子就是另一段行情 |

规则：初始资金 10,000 USDT；市价单按当前最后一根 K 线收盘价成交；手续费 0.05%；最多 10 倍杠杆；
同向下单为加仓，反向下单先平再开（反手）。止盈止损在下一根 K 线出现时检查：开盘价已越过则按开盘价成交，
否则阳线按「开→低→高→收」、阴线按「开→高→低→收」的顺序判断先碰到哪个。最大回撤按每根 K 线收盘时的账户权益计算。

快捷键：空格 下一根 · P 播放/暂停 · B 做多 · S 做空 · C 平仓 · 图表滚轮缩放、拖动平移、双击回到最新。
