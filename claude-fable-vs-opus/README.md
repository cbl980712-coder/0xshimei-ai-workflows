# Claude Fable 5.2 vs Opus 5.5：同一句话做两个币圈小工具

Claude 在 2026-11-09 发布 Fable 5.2。我把两个模型放在 Claude Code 里，用一模一样的提示词各做了两个工具，中途不追加任何指令。这里是四个成品的全部源码、原始提示词和截图，下载就能用，也能自己对比。

## 两个工具

| 文件夹 | 是什么 | 怎么用 |
|---|---|---|
| `仓位计算器/` | 合约仓位计算器：输入本金、杠杆、开仓价、做多/做空，算出仓位价值、强平价（逐仓、维持保证金率按 0.5% 估算），以及价格涨跌 1%/5%/10% 时的盈亏和收益率，价格轴上标出开仓价和强平价 | 双击 `index.html` 用浏览器打开 |
| `K线回放练习器/` | 300 根模拟 BTC 1 小时 K 线，逐根回放或自动播放，市价做多做空、止盈止损，统计胜率、最大回撤和每笔记录，回放结束出总结 | 双击 `index.html` 用浏览器打开；空格下一根，B 做多，S 做空，C 平仓 |

每个工具下面有 `opus-5.5/` 和 `fable-5.2/` 两个版本。都是纯网页，不联网、不用装任何东西，手机浏览器也能打开。K 线数据是程序生成的模拟数据，不是真实行情。

## 实测数据（Claude Code 2.1.321，各模型默认档位，同时开跑）

| | 仓位计算器 | K 线回放练习器 |
|---|---|---|
| Opus 5.5 | 3 分 8 秒 · 18 轮 · 按 API 价折算 $0.94 | 8 分 37 秒 · 37 轮 · 折算 $2.11 |
| Fable 5.2 | 6 分 4 秒 · 28 轮 · 折算 $2.90 | 8 分 36 秒 · 31 轮 · 折算 $3.86 |

验收方法：无头浏览器打开每个成品，电脑和手机两种尺寸截图；回放练习器点做多、回放 15 根、平仓、做空、回放 20 根、平仓，再回放到底。四个成品都没有页面报错，按钮都能用，强平价两边用的是同一个公式，手算核对过都对。

两边的差别（只说看到的）：
- 仓位计算器：Fable 版多了可以拖动的价格探针，拖到任意价格直接显示盈亏，并把价格轴分成盈利区、亏损区、强平区；Opus 版把仓位价值、数量、强平价、距强平做成四张卡片放在顶部，信息一屏看完。
- 回放练习器：两边功能都齐。Opus 版在 K 线图上标出每笔开仓和平仓的位置，统计里单列手续费；Fable 版加了缩放按钮、下单金额倍数按钮，并写明同一根 K 线同时碰到止盈和止损时按止损算。

没测的：止盈止损自动触发、长时间自动播放。

## 原始提示词

见 `提示词原文.md`，两个模型拿到的完全一样。想自己复现：在 Claude Code 里新建空文件夹，`--model` 分别选 `claude-opus-5-5` 和 `claude-fable-5-2`，把提示词贴进去。

## 免责

仓位计算器的结果是估算，实际强平价以交易所为准（维持保证金率分档、手续费、标记价格规则各家不同）。回放练习器只用于练习，不构成投资建议。
