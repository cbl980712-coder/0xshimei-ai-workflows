# 提示词包（不跑脚本，直接贴给任意聊天 AI）

## 提示词 1：整理成 CSV
```
下面是我收藏的设计网站（可能是书签、笔记或聊天记录）。请整理成 CSV，表头固定为：名称,网址,简介,分类。
规则：1) 简介只能用我给的文字，我没写的留空，不要自己编；2) 网址原样保留；3) 分类按我给的分组名填，没有就留空。
只输出 CSV。
【粘贴内容】
```

## 提示词 2：筛选推荐
```
我要做【落地页/产品界面/运营图】，眼下卡点是：【一句话】。
下面是我的收藏清单 CSV。请：
1. 按网址合并重复项（忽略 http/https、www、末尾斜杠、utm 参数），简介保留较长的那条；
2. 把「简介少于 12 个字」或「看不出能解决什么问题」的站列成待补清单，不要推荐它们；
3. 只从清单里推荐最多 3 个站，每个站说明：适合解决什么问题、依据清单里哪句简介。依据必须是简介原文，不准补充你自己对这个站的印象；
4. 3 个站尽量覆盖不同的卡点，不要三个都是同一类；
5. 最后一行写：以上推荐没有联网核对过链接。
【粘贴 CSV】
```
