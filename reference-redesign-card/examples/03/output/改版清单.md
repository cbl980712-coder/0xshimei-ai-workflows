## 二、这些地方不动

- **912px 宽的 JSON 编辑框（左侧）**：这是工具本体：粘贴长 JSON 需要宽度；TinyPNG 的 760px 居中框是为拖图设计的，不借鉴
- **顶部 11 个工具标签（Validate / Format / Repair …）**：用户靠它在工具之间切换，是这类站点的核心导航，不动
- **Validate 的蓝色 #0a84ff**：品牌色与参考页不同，保持，只借“一实多虚”的关系
- **编辑框下方的 Tip 和 JSON Formatter 等链接**：SEO 内链，不动

不借鉴（参考页有，但不适合我的目标）：

- TinyPNG 的熊猫大图背景：与 JSON 工具的气质不符，且会拖慢加载
- 参考页首屏的聊天悬浮按钮（Need a hand?）：这是客服插件，不是设计

## 三、改版清单（按优先级）

### P0-1　Validate 放大，成为按钮组里最大的一个　〔P0·先改（影响最大）〕

- **改哪里**：button.btn.btn-primary（Validate）
- **怎么改**：高度 38 → 48px，左右内边距 28px，字号 14 → 16px，字重 600。其余按钮保持原大小。
- **参考样式**：

```css
button.btn.btn-primary { height:48px; padding:0 28px; font-size:16px; font-weight:600; }
```

- **怎么看改对了**：一眼最大最亮的是 Validate；量：高 ≥ 46px、字号 ≥ 16px
- 来自借鉴点：B1

### P0-2　其余按钮去掉描边，变成文字按钮　〔P0·先改（影响最大）〕

- **改哪里**：button.btn.btn-secondary（Clear / Compress / Sort Keys / Copy）
- **怎么改**：边框透明、背景透明，文字和悬停效果保留。保证它们仍可点（尺寸不变），只是不再画框。
- **参考样式**：

```css
button.btn.btn-secondary { border-color:transparent; background:transparent; }
```

- **怎么看改对了**：按钮组里只有 Validate 是有框有底色的；量：次要按钮背景和边框都是透明
- 来自借鉴点：B1

### P1-1　页面标题放大加重　〔P1·再改〕

- **改哪里**：h1（JSON Validator）
- **怎么改**：24px/700 → 32px（字重原本就是 700，保持不变）（与正文比从 1.5 倍到 2 倍；TinyPNG 是 2.67 倍，工具站不需要那么大，取中间值）。 注意：站点用工具类（如 text-2xl）设字号，只写 h1 { … } 压不过，要写 h1[class] { … } 抬高优先级。
- **参考样式**：

```css
h1[class] { font-size:32px; font-weight:700; }
```

- **怎么看改对了**：标题明显比下面那行说明大一档；量：字号 ≥ 32px，字重 ≥ 700
- 来自借鉴点：B2

### P1-2　编辑框和按钮组之间拉开　〔P1·再改〕

- **改哪里**：div.space-y-3 > div.flex.flex-wrap（按钮组容器）
- **怎么改**：上外边距 12px → 24px，按钮之间 8px，垂直居中对齐（Validate 变高后其他按钮不再顶着上沿）。
- **参考样式**：

```css
.space-y-3 > .flex.flex-wrap { margin-top:24px; gap:8px; align-items:center; }
```

- **怎么看改对了**：编辑框底边与按钮组之间有明显空隙；量：按钮组上外边距 ≥ 24px
- 来自借鉴点：B3
