## 三、改版清单（按优先级）

### P0-1　把 Quickstart 链接变成实心按钮（最小改法：只改样式）　〔P0·先改（影响最大）〕

- **改哪里**：第 1 段里的链接 Quickstart（#welcome-to-flask p a[href="quickstart/"]）
- **怎么改**：改成 inline-block，高度 ≥40px，圆角 8px，底色 rgb(66,184,131)，白字，去下划线。彻底改法（要改 HTML）：单独放一行按钮区。
- **参考样式**：

```css
#welcome-to-flask p a[href="quickstart/"] { display:inline-block; padding:11px 16px; border-radius:8px; background:rgb(66,184,131); color:#fff; text-decoration:none; border-bottom:0; }
```

- **怎么看改对了**：人看：首屏能一眼看到绿色按钮；量：高度 ≥40、圆角 ≥8
- 来自借鉴点：B1

### P1-1　拉开第 1、2 段之间的留白　〔P1·再改〕

- **改哪里**：第 2 段（#welcome-to-flask > p:nth-of-type(2)）
- **怎么改**：margin-top 从 17px 加到 40px（参考页中位数 83px 是整个首屏的，文档页取一半以内以免挤掉内容）
- **参考样式**：

```css
#welcome-to-flask > p:nth-of-type(2) { margin-top:40px; }
```

- **怎么看改对了**：人看：两段之间明显分开；量：marginTop ≥ 40
- 来自借鉴点：B2
