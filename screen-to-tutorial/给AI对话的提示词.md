# 不用 Claude Code：把这段贴给任何能看图的 AI 对话

适用于 ChatGPT、Claude 网页版、豆包、Gemini 等能上传图片的对话窗口。

**怎么用**
1. 先跑完第 ① 步（切关键帧），`work/` 文件夹里会有 `contact_sheet.jpg`、`frames/` 和 `steps.draft.json`。
2. 打开 AI 对话，上传 `contact_sheet.jpg`（想更准就把 `frames/` 里的每张图也一起传）。
3. 把下面整段提示词贴进去，再把 `steps.draft.json` 的全部内容贴在最后。
4. AI 回复的 JSON 原样保存成 `work/steps.json`，然后跑第 ③ 步出 HTML。

---

```
我在做一份软件操作的图文教程。上传的图是一段录屏切出来的关键画面：
contact_sheet.jpg 把所有画面按顺序拼在一起，左上角编号 00 是起点，01、02……是每一步操作之后的画面。

软件/网站：【填软件名】
这段操作要完成的任务：【填任务，比如「把图片压缩成 WebP」】
教程语言：中文

请对照相邻两张画面（00→01、01→02……），判断每一步用户做了什么操作，然后把我最后贴的 JSON 填完整：
- title：整份教程的标题，说清软件和任务。
- subtitle：一句话说明前提或用时。
- 每个 step 的 title：动作名称，动词开头，20 字以内，比如「点击右上角头像，打开账户菜单」，不要只写页面名。
- 每个 step 的 desc：2～3 句。第一句说在哪里、怎么操作（位置用左上角、右侧菜单、弹窗底部这类词；按钮和菜单名照界面原文写，用「」括起来）；第二句说操作后界面变成什么。
- 每个 step 的 tip：容易做错的地方或前提，一句话；没有就写空字符串。
- box：红框位置，[左, 上, 宽, 高]，单位是图片宽高的百分比；框住这一步变化的地方。JSON 里已经有程序算好的候选框，对就保留，不需要框就删掉这个字段。
- 只写图里看得见的东西，看不清的字不要猜。
- 不要改 image、time 字段。

只输出填好的完整 JSON，不要解释。

【在这里贴 steps.draft.json 的全部内容】
```
