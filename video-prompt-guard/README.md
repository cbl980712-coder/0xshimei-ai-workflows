# AI 视频抽卡前的分镜检查（video-prompt-guard）

用可灵、即梦、Vidu、Veo 这类工具做视频，一个镜头反复生成十几次还在崩，钱就这么烧掉了。
这个工具在你**生成之前**先检查分镜：哪些镜头容易翻车、为什么、该怎么拆怎么改，再给你写好首尾帧提示词，算出修改前后大概要花多少钱。

- 只要 Python 3.8+，**不用装任何包**，不联网，不要账号和 API Key，不花钱。
- 能单独用，也能放进 Claude Code 当 Skill，让它照流程帮你改分镜。
- 没装 Python 的话，`网页AI提示词.md` 里有一段提示词，贴给任意 AI 对话也能做检查（只是不会算成本）。

## 你会得到什么

跑一次，`out/` 文件夹里有四个文件：

| 文件 | 内容 |
|---|---|
| `report.md` | 每个镜头的风险分、命中了什么问题、怎么改，带勾选框的自检清单 |
| `final_prompts.md` | 套好首尾帧约束和负向词的提示词，按镜头分好，贴进视频平台的首尾帧模式 |
| `cost.csv` | 每个镜头的风险分、预估要抽几次、预估花多少钱 |
| `result.json` | 同样的内容，给别的程序读 |

`examples/` 里有三组真实跑过的例子（AI 短剧、产品口播、创意变身），每组都有原稿、修订稿，以及两次检查出来的报告和提示词，可以先打开看看效果。

## 第 1 步：准备

- Mac：自带 `python3`，打开「终端」就能用。
- Windows：到 python.org 装 Python，下面命令里的 `python3` 换成 `python`。

下载这个文件夹（仓库首页绿色的 Code → Download ZIP，解压），在终端里进到 `video-prompt-guard` 文件夹。

先跑一下自带的例子，确认环境没问题：

```bash
python3 prompt_guard_checker.py examples/01-短剧-雨夜追逐/原稿.md -o out_试跑
```

看到「镜头 4 个 | 高风险(>=5分) 3 个 …」这一行就说明能用了。

## 第 2 步：写你的分镜

新建一个文本文件，比如 `shots.md`，一个镜头一段：

```
镜头1：雨夜小巷，女主站在路灯下，穿红色风衣，缓慢推镜
首帧：女主侧身站在路灯下，低头
尾帧：女主抬头望向镜头
时长：4秒

镜头2：……
```

首帧、尾帧、时长可以不写，脚本会提醒你并先起草一版。英文写 `Shot 1:`。拆镜以后可以叫 `镜头1b`、`镜头1-2`。

## 第 3 步：检查

```bash
python3 prompt_guard_checker.py shots.md -o out
```

单次生成价默认按 4 元算，换成你平台的实价：`--price 2.5`。

打开 `out/report.md`：

- 风险分 0～1 低，2～4 中，5～8 高，9 以上极高。
- 标了「仍高风险」的镜头先别生成。按清单拆镜、改写（打斗和拥抱只拍接触前后；画面里的字后期再加；大角度环绕改成小幅；超过 5 秒拆开），存成 `shots_fixed.md` 再跑一次，直到没有「仍高风险」。
- 然后把 `out/final_prompts.md` 里的提示词贴进平台的首尾帧模式。先用最低档、最短时长试一条，过了再出高清。

## 第 4 步（可选）：算修改前后的成本

```bash
python3 prompt_guard_checker.py shots_fixed.md -o out_fixed
python3 build_xlsx.py out out_fixed -o 我的成本表.xlsx --price 4
```

表格按镜头名对照，拆镜新增的镜头会单独列一行。「参数」页可以改单价和失败率，表格自动重算。
自带的 `shot_cost_calculator.xlsx` 是三组例子的对照：12 个镜头预估从 ¥232 降到 ¥52。

## 用 Claude Code 跑

把整个文件夹放到 `.claude/skills/video-prompt-guard/`，在 Claude Code 里说「帮我检查这几个分镜」，再把分镜贴给它。它会按 `SKILL.md` 的步骤跑脚本、拆镜改写、重跑，直到没有高风险镜头。

## 先知道这些限制

- **成本是估算，不是实测。** 失败率用的是一个假设公式（0.10 + 0.08 × 风险分，最高 0.85），成本表里修订稿还假设首尾帧约束让失败率再乘 0.6，这几个数都没有在视频平台上实际验证过。你自己生成后把真实抽卡次数填进成本表，把参数调成你的。
- **只认写出来的词。** 规则是关键词匹配，比如写了「拥抱」「360度」「招牌上写着」会被抓到；没写出来的风险，比如一个镜头里塞了三个动作但没用这些词，它看不出来。
- **只检查文字。** 不检查你的首尾帧图片本身。
- 格式不对时（没写「镜头1：」），会按空行把每段当一个镜头。完全没内容会提示你检查格式。

## 文件

| 文件 | 作用 |
|---|---|
| `prompt_guard_checker.py` | 检查脚本，只用 Python 自带库 |
| `build_xlsx.py` | 生成成本对照表（不用装 Excel 相关的包） |
| `SKILL.md` | Claude Code Skill 的步骤 |
| `low_cost_lock_template.md` | 自己手写提示词时用的首尾帧模板 |
| `网页AI提示词.md` | 不装 Python，贴给任意 AI 对话用 |
| `shot_cost_calculator.xlsx` | 三组例子的成本对照 |
| `examples/` | 三组例子：原稿、修订稿、两次检查的报告和提示词 |
