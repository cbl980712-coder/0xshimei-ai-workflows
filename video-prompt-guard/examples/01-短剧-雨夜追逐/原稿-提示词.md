# 标准首尾帧提示词

## 镜头1
```
【⚠ 仍高风险：先按自检清单拆镜，下面的首尾帧只是自动草稿，不要直接去抽卡】
【主体与场景】雨夜小巷，两个男人在打斗，镜头小幅环绕(不超过30度)缓慢推进，他抱起女主奔跑，背景是背景虚化的少量路人(不超过3人,无清晰面孔)围观，招牌上写着"老王面馆"。
【首帧】雨夜小巷（起始静态姿态，自动起草，请核对）
【尾帧】招牌上写着"老王面馆"（结束稳定姿态，自动起草，请核对）
【运动】只描述首帧到尾帧之间的一个连续动作；运镜：单一、缓慢、平稳。
【死锁约束】人物外貌/服装/发型/光线/场景在首尾帧保持一致；主体数量不变；不新增画面外元素；画面内不出现文字；时长 ≤5 秒。
【负向】画面抖动, 闪烁, 面部变形, 五官漂移, 多余肢体, 画质模糊, 水印, 乱码文字, 人脸融合, 糊脸, 人群克隆, 多余手指, 手指融合, 肢体穿模, 多手多脚, 关节反向弯曲, 镜头突变, 画面撕裂, 运动拖影, 背景扭曲, 景别跳变, 文字变形, 错别字, 招牌乱码, 品牌标识变形
```
