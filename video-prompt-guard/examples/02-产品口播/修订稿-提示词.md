# 标准首尾帧提示词

## 镜头1
```
【主体与场景】博主坐在桌前，面向镜头，桌上放着一杯咖啡。
【首帧】博主坐在桌前，双手放在桌下，半身
【尾帧】博主微微点头，半身
【运动】只描述首帧到尾帧之间的一个连续动作；运镜：单一、缓慢、平稳。
【死锁约束】人物外貌/服装/发型/光线/场景在首尾帧保持一致；主体数量不变；不新增画面外元素；画面内不出现文字；时长 ≤5 秒。
【负向】画面抖动, 闪烁, 面部变形, 五官漂移, 多余肢体, 画质模糊, 水印, 乱码文字
```
