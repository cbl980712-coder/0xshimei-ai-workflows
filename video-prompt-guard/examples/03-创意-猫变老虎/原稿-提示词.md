# 标准首尾帧提示词

## Shot 1
```
【⚠ 仍高风险：先按自检清单拆镜，下面的首尾帧只是自动草稿，不要直接去抽卡】
【主体与场景】一只橘猫趴在窗台上，它慢慢变成一只老虎，然后跳下窗台跑向花园。
【首帧】一只橘猫趴在窗台上（起始静态姿态，自动起草，请核对）
【尾帧】然后跳下窗台跑向花园（结束稳定姿态，自动起草，请核对）
【运动】只描述首帧到尾帧之间的一个连续动作；运镜：单一、缓慢、平稳。
【死锁约束】人物外貌/服装/发型/光线/场景在首尾帧保持一致；主体数量不变；不新增画面外元素；画面内不出现文字；时长 ≤5 秒。
【负向】画面抖动, 闪烁, 面部变形, 五官漂移, 多余肢体, 画质模糊, 水印, 乱码文字, 额外人物, 主体替换, 人物数量变化, 多余手指, 手指融合, 肢体穿模, 多手多脚, 关节反向弯曲, 物体凭空出现/消失, 形态突变, 中途切换
```
