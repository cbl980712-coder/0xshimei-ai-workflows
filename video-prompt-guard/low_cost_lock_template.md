# 防崩坏首尾帧提示词死锁模板

用法：每个镜头（≤5 秒）复制一份，把 `[ ]` 里的内容换成你的。脚本 `prompt_guard_checker.py` 会按这个结构自动生成草稿。

```
【主体与场景】[谁(最多2个) + 在哪 + 穿什么 + 光线]，一句话，不用代词
【首帧】[景别 + 主体位置 + 姿态 + 表情]   ← 同时用图生成一张首帧图
【尾帧】[景别 + 主体位置 + 姿态 + 表情]   ← 同时用图生成一张尾帧图
【运动】只写首帧到尾帧之间的一个连续动作；运镜：单一、缓慢、平稳（只选一种：推/拉/摇/移/固定）
【死锁约束】人物外貌/服装/发型/光线/场景在首尾帧保持一致；主体数量不变；不新增画面外元素；画面内不出现文字；时长 ≤5 秒
【负向】画面抖动, 闪烁, 面部变形, 五官漂移, 多余肢体, 画质模糊, 水印, 乱码文字
        [按风险追加，见下表]
```

## 负向参数按风险追加

| 命中风险 | 追加到负向 |
|---|---|
| 肢体冲突/手部 | 多余手指, 手指融合, 肢体穿模, 多手多脚, 关节反向弯曲 |
| 镜头剧烈 | 镜头突变, 画面撕裂, 运动拖影, 背景扭曲, 景别跳变 |
| 歧义/多主体 | 额外人物, 主体替换, 人物数量变化 |
| 人群 | 人脸融合, 糊脸, 人群克隆 |
| 文字/Logo | 文字变形, 错别字, 招牌乱码, 品牌标识变形 |
| 状态突变 | 物体凭空出现/消失, 形态突变, 中途切换 |

注意：有的平台没有「负向」输入框，就把负向改写成正向句塞进约束里（如「画面稳定，手指数量正常」）。

## 首尾帧对齐 5 条硬规矩

1. 首帧图和尾帧图用同一个人物参考图/同一个种子风格生成，别分两次随便抽。
2. 首尾帧的人物数量、服装、光线、背景必须一致，只允许变「姿态/位置/景别」。
3. 首尾帧之间的动作量要小：一个动作，不是一段剧情。
4. 大变化（变身、爆炸、转场）拆成两个镜头：镜头A尾帧 = 变化前，镜头B首帧 = 变化后。
5. 先用最短时长/最低档抽 1 条试片，过了再出高清。

## 翻车项速查（改写口诀）

- 打斗 / 拥抱 / 握手 → 只拍接触前、接触后，或用遮挡
- 手部精细操作 → 手出画 / 半身构图 / 物体静置
- 360° 环绕 / 快速推拉 / 手持晃动 → 小幅、缓慢、稳定器
- 人群 → ≤3 个虚化路人
- 招牌、屏幕、字幕 → 画面不出字，后期叠
- 一镜到底 / >5 秒 → 拆镜
