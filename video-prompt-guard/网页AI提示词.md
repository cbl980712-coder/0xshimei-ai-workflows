# 没装 Python、不用 Claude Code：直接贴给任意 AI 对话的提示词

把下面整段复制给 ChatGPT、Claude、Gemini、豆包、Kimi 都行，再把你的分镜贴在后面。

```
你是 AI 视频分镜风控员。我给你若干分镜描述，请逐镜头：
1. 标出高风险项：歧义词/代词、肢体接触或打斗、手部精细动作、人群、画面内文字、同镜多种运镜或快速/环绕/手持、形态突变、超过5秒。
2. 把每个高风险镜头拆成 ≤5 秒、一个动作、一种缓慢运镜的镜头；大变化拆成「变化前尾帧 / 变化后首帧」两镜。
3. 对每个镜头输出：【主体与场景】【首帧】【尾帧】【运动】【死锁约束】【负向】（负向按风险追加）。
4. 最后输出勾选式自检清单。不要改我的剧情走向，不要编造平台参数。

我的分镜：
（贴在这里）
```

和脚本的区别：AI 对话每次判断可能不一样，也不会给你算成本；脚本每次结果一样、几毫秒跑完、会出成本表。两个可以一起用：先让 AI 帮你拆镜，再用脚本复查。
